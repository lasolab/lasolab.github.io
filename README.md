# LASO Lab website

Source code for **[lasolab.github.io](https://lasolab.github.io)**, the website of the Landscape, Accessibility, and Spatial Observation Lab (Environmental Studies, Western Washington University).

The site is built with [Quarto](https://quarto.org) and published to GitHub Pages by GitHub Actions on every push to `main`.

Questions or corrections: [lasof@wwu.edu](mailto:lasof@wwu.edu)
